A bit about me

I like making electronics that work on a real desk, not just on paper.

Most of my projects start as a schematic, turn into a PCB, and end up running ESP32 firmware.

When a project needs a case, I model it in Onshape. When it needs to be reachable, I set up the server and the network behind it, and I run my own SSH servers. I also vibe-code with Claude to move faster when an idea is bigger than my evenings.
